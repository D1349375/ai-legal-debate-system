# 律師視角 UI 整理(ui-lawyer-polish)

基準：`demo-mode`(a39089c)。依據：Claude Doc「律師視角 UI 檢視與優化建議」(2026-11-05)。組長同意在分支上修改 `ui/`。
只改 `ui/app.js`、`ui/app.css`、`ui/legal_workspace_ui.html`；API 與後端不變。檢視案例：`v2-2026-11-04-construction`，1440×900。

## 改了什麼

| 項目 | 改法 |
|---|---|
| 分頁名稱 | 起訴前檢查→當事人與管轄、起訴狀(P1)→起訴狀、答辯狀(P2)→對方答辯(模擬)、爭點整理表(P3)→爭點整理、書狀交換(P4–P5)→攻防模擬、診斷與 v2(P6)→弱點與修改建議、引用查證→引用查核(只改新流程；舊流程分頁不變) |
| 用語 | 畫面上不再出現 P0–P6、「落地」、「關卡 1」、I1／CF2 代號(改「爭點 1」「事實 2」)、「S1」(新流程改書狀名稱)；時間改台灣時間 |
| 錄製標示 | 「⏺ 錄製紀錄」各頁不再重複，改在頂部列標一次「示範資料(錄製重播)」；即時生成照舊逐筆標 |
| 頂部列 | 標題改「原告 對 被告」，副標是案由與建立時間 |
| 總覽 | 第一屏是 4 個可點的結果數字(爭點強弱、待補證據、修改建議、引用)＋下一步；未經律師確認時多一列提醒；流程進度跑完時收合 |
| 當事人與管轄 | 時效／程序提示直接攤開；兩造管轄併成一張卡；資料來源與授權只在頁底列一次 |
| 起訴狀 | 版本鈕改「初稿・流程採用」「修訂版(依診斷建議)」；確認提示改「尚未經律師確認」；0 項的起訴審查不顯示 |
| 對方答辯 | 鎖頭說明改白話「模擬的對方律師只看得到你的起訴狀…」 |
| 爭點整理 | 爭點表 8 欄→5 欄，爭點全文不截斷，證據與法條改小字；表名改「爭點(表三)」等，說明順序 |
| 攻防模擬 | 切換鈕改「第一次書狀往返(準備書狀)／最後辯論(意旨狀)」；強弱徽章加「我方」 |
| 弱點與修改建議 | 強弱、理由、缺什麼證據合成「一個爭點一張卡」，預設收合成一行，「展開弱的爭點」一鍵展開；修改建議表與修訂版差異保留 |
| 引用查核 | 全部通過時四格統計改一句話；通過的收成一張精簡表；查詢設定收進「查證設定」；有問題的照舊逐條列細節(舊流程也套用) |
| 側欄 | 預設只列新流程且已存入資料庫的案件，「顯示全部(N)」切換 |
| 右側欄 | 新流程案件不顯示(內容與頂部重複)；技術細節移到總覽「完整案件輸入與技術細節」，免責聲明在每頁底部 |
| demo | 網址加 `?demo=1` 直接進專注模式 |
