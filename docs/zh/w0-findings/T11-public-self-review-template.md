## 問題

M15 讓雙方把自我弱點寫進 `【內部檢討】…【內部檢討結束】`,法官讀不到。但 Stage 2、3 範本的步驟又要求在公開論證裡寫評估:

- `stage2_prompt.txt` 步驟三「交叉判斷主要路徑是否已受重創、備位是否該啟用」,JSON 說明寫 `argument` 要含「主路徑受挫評估」。
- `stage3_prompt.txt` 步驟二「逐一標記每個候選…「仍站得住」「已被打掉」「未經檢驗」」,JSON 說明寫 `argument` 要含「逐項現況標記」。

兩個要求互相衝突,模型就把評估寫在段落外。C1 段落外 2 句自我評估都出在這兩步:

- 原告 Stage 2:「原告對此備位路徑須承認有明顯時效風險,因此本輪將公司法第23條第1項置於主軸」。
- 被告 Stage 3:「本方Stage2提出的「清算人知悉即歸屬公司」規則無判例依據,法院採對造說的風險高。」**法官評估引用了這句**,寫成對被告不利。

T4 的詞表沒抓到這 2 句。再補詞會抓到更多正常的策略用語(T4 量測過「我方承認」誤報 14/25)。從源頭讓這些評估寫進段落,比補詞有效。

## 要做的

只改兩份範本的文字,不改程式:

1. **`stage2_prompt.txt` 步驟三**:
   - 「是否已受重創」「風險高低」「力道是否減弱」「法院可能採哪一說」這類評估,寫在 `【內部檢討】` 段落內。
   - 段落外只寫結果:本輪的主要主張、是否啟用或並陳備位、理由(法律論點或案件資料)。
   - 內部一致性檢查的**結論**(有沒有互相矛盾、怎麼調整)可以留在段落外;檢查過程中對自己的風險判斷放段落內。
2. **`stage3_prompt.txt` 步驟二、三**:
   - 每個候選的「仍站得住/已被打掉/未經檢驗」標記與理由放在段落內。
   - 段落外對每個候選只寫處置:繼續主張、改列備位,或不再主張。不再主張要寫依據,同「資料紀律」:只能因案件資料直接否定或對方法律論點確實成立。V37 要能從公開論證看出撤回理由。
3. **兩份的 JSON 說明**(檔尾 `"argument": "…"`)同步改:受挫評估、現況標記寫在內部檢討段落,段落外寫處置與理由。
4. **兩份的「內部檢討段落」那一段**:舉例列出要放進段落的寫法,用 C1 的兩句改寫成「例如:某路徑風險高、法院可能採對造說、須承認有時效風險」。**不要**貼 C1 原句全文。
5. 不動的地方:`falsifier`(讓步條件本來就是公開的假設句)、協議必答項 (a)(b)(c)、補正追問與準備題的紀律、引用格式鐵律。

不要做:不新增 JSON 欄位(分類器風險,共同規則第 8 點);不改 `engine/internal_review.py` 的詞表(T4 的範圍);不改法官範本;不改 SKILL 的步驟順序。

## 風險(寫進紀錄,C3 時看)

- 段落內的內容變多。M15 加段落時「會不會更容易觸發 `reasoning_extraction` 分類器」還沒定論(W0、C1 都是中止 0 次,單次不能當結論)。
- 法官讀到的資訊變少:要確認評估仍逐一處理每個候選(看得到雙方繼續主張、改列備位、不再主張),不會因此漏掉爭點。
- 對手摘要的「最強論點」仍從公開論證摘,不受影響。

## 測試

範本是給模型讀的文字,離線測試驗不出效果。可以加一個簡單測試確認兩份範本都寫了「受挫評估/現況標記寫在內部檢討段落」,避免之後被改回去;不加也可以,理由寫進紀錄。改完跑離線全套,確認沒有測試綁著舊文字。

- 離線全套通過。
