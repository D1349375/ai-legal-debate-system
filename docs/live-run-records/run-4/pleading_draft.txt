為請求撤銷詐害債權行為及塗銷所有權移轉登記提起訴訟事:

訴之聲明
一、被告甲、乙間就系爭房地於民國104年7月15日所為之贈與行為,及於同年7月27日所為之所有權移轉登記行為,均應予撤銷。
二、被告乙應將前項所有權移轉登記予以塗銷。
三、訴訟費用由被告負擔。
(範本之「願供擔保,請准宣告假執行」一項,本案為形成之訴與塗銷登記,是否列入由律師決定,本骨架不擅自增列。)

事實及理由
一、事實(取自案件事實輸入,未增減)
(一)原告公司於民國104年4月間解散。被告甲自99年7月20日起擔任原告公司董事,原告公司解散後仍任清算人。
(二)原告公司於101年至103年間分別進、銷貨計新臺幣2,300萬4,706元、2,703萬1,489元,未依規定取得進貨憑證,亦未依法開立銷售統一發票,逃漏營業稅135萬1,573元,經財政部中區國稅局於104年2月10日查獲,裁處原告公司罰鍰200萬元;原告主張得就此向被告甲請求賠償。
(三)被告甲於104年7月15日將其所有之房地(下稱系爭房地)贈與其配偶即被告乙,並於同年7月27日完成所有權移轉登記;原告主張被告甲為上開贈與時名下已無其他財產。
(四)原告公司於112年10月12日申請調閱系爭房地登記謄本,始知上開贈與及移轉登記。

二、理由(原告方 Stage 3 最終立場,逐字套入,未潤飾)
最終立場:最終立場收斂為單一、內部一致的路徑:以公司法第23條第1項董事對公司之損害賠償債權(罰鍰200萬元)為被保全債權,依民法第244條第1項、第4項,撤銷甲、乙間104年7月15日贈與及同年7月27日移轉登記,並命乙塗銷登記。本方正式放棄民法第184條、第179條、第87條及公司法第79條、第84條清算人責任等所有並陳或備位主張。本方在程序上主張丙之代表權依最高法院115年度台抗字第105號意旨由法院依職權調查,待補正。撤銷之訴能否成立,繫於三件卷內未載之事實:起訴日須在114年7月15日前、甲贈與時無其他足額財產、甲對公司負有可歸責之賠償債務。其中任一不成立,本方即讓步。

(一)撤銷權(民法第244條第1項、第4項):贈與為無償行為,債權早於行為成立,不須證明乙之惡意。
(二)被保全債權(公司法第23條第1項):甲自99年7月20日任董事,為公司負責人(公司法第8條)。公司連續三年(101至103年)、進銷貨合計逾5,000萬元均未取得憑證或開立發票,不是單一偶發疏失,而是持續性經營管理缺失,自然引出「負責人是否盡到注意義務」之疑問。本方不主張這已構成證明,卷內確實沒有直接證明甲實際經手或有過失的證據;依民事訴訟法第288條聲請調取財政部中區國稅局裁處書及查獲卷證,以證明受處分對象、實際經手人及甲之參與程度。本方只主張200萬元罰鍰為損害,不主張營業稅本稅,繳納情形併於調卷時確認。
(三)害及債權:原告主張甲贈與時名下已無其他財產,卷內目前無資料,將聲請調閱甲104、105年度綜合所得稅各類所得資料、財產歸屬資料及系爭房地登記謄本;調閱結果若顯示甲仍有足額財產,此要件不成立,本方不迴避。
(四)除斥期間(民法第245條):行為日104年7月15日,10年期限至114年7月15日,起訴日卷內未載,須以本案收狀戳記確認,若收狀日晚於114年7月15日,本方就撤銷之訴讓步。1年期間:本方主張知悉點為112年10月12日調閱謄本;惟甲兼任清算人而為行為人,其知悉是否即公司之知悉,待法院認定,若法院認定甲之知悉即屬公司知悉且起訴逾該時點起1年,本方讓步。
(五)時效:公司法第23條第1項責任若適用民法第125條15年期間,自104年起算尚未屆滿;其性質是否屬侵權行為類型而適用民法第197條,待查證引擎確認,屬本方承擔之風險。
(六)程序事項現況(待補正):丙之代表權待補正。本方將於補正期間提出解散前公司變更登記表、股東名冊、章程、股東同意書及清算人向法院聲報就任之資料(若有)。查明前不主張丙已合法就任,也不編造任何姓名或文件。甲因是本案被告又曾任清算人,利益衝突,本方聲請法院確認有適格代表人,必要時依公司法第113條準用第81條另行選派。依最高法院115年度台抗字第105號裁定意旨,法院應依職權調查法定代理權,公司負責人之登記僅屬對抗第三人之要件(公司法第12條);惟該案調查基礎為董事委任及出資受讓效力另有爭執,引用時宜限縮為「有實質爭議時,不得僅憑登記駁回」,且該裁定不能治癒代表權欠缺本身。若查明確無代表權且逾期不補正,依民事訴訟法第249條第1項,起訴不合法。
(七)舉證責任:民事訴訟法第277條。
(八)本方讓步條件(falsifier):(一)收狀日晚於114年7月15日;(二)甲贈與時仍有足額清償200萬元之其他財產;(三)國稅局裁處書與卷證顯示甲非實際經手人或無過失,或罰鍰公司並未繳納而無損害;(四)法院認定甲之知悉即屬公司知悉,且起訴逾該時點起1年;(五)丙經限期補正仍無法證明代表權且法院查明確無代表權。
