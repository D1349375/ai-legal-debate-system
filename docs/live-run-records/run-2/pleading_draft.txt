為請求撤銷詐害債權行為及塗銷所有權移轉登記提起訴訟事:

訴之聲明
一、被告甲、乙間就系爭房地於民國104年7月15日所為之贈與行為,及同年7月27日所為之所有權移轉登記行為,均應予撤銷。
二、被告乙應將系爭房地於民國104年7月27日以贈與為原因所為之所有權移轉登記予以塗銷。
三、訴訟費用由被告負擔。
(假執行之聲請:範本有「願供擔保,請准宣告假執行」一項,本案為形成之訴及塗銷登記之訴,是否適宜聲請待律師判斷,骨架版不列。)

事實及理由
一、無實質爭議事項(一筆帶過):被告甲於104年7月15日將其所有之系爭房地贈與配偶即被告乙,並於同年7月27日完成所有權移轉登記;該贈與為無償行為;原告公司於101至103年間之逃漏營業稅行為及104年2月10日經財政部中區國稅局查獲、裁處罰鍰200萬元,均早於上開贈與;原告公司於104年4月解散,被告甲解散後任清算人。

二、請求權基礎:原告依民法第244條第1項、第4項規定,請求撤銷上開贈與行為及移轉登記行為,並命被告乙塗銷該登記。債務人所為之無償行為,有害及債權者,債權人得聲請法院撤銷之,且不以受益人惡意為要件;債權人聲請撤銷時,得並聲請命受益人回復原狀。

三、被保全債權:原告公司對被告甲有因其任董事及清算人期間違反忠實與善良管理人注意義務所生之損害賠償債權(公司法第23條第1項、第108條第1項;清算人部分依公司法第113條準用第84條及民法第535條、第544條),定性為債務不履行,適用一般請求權時效(民法第125條)。請求範圍以罰鍰200萬元為限,不含補徵稅款135萬1,573元(補稅本為公司應納稅款,非因被告甲違反義務而多出之損害)。【卷內目前未見證據證明被告甲是否為101至103年間負責進貨憑證取得及統一發票開立之人、義務違反與罰鍰間之因果關係;舉證責任在原告(民事訴訟法第277條),待調閱國稅局裁罰書、查核卷、公司帳務分工資料等補強。】

四、有害及債權(無資力):原告主張被告甲贈與時名下已無其他財產。【卷內目前未見財產清冊、房地價值或甲剩餘財產資料,待調閱財產歸屬資料清單、地政謄本、課稅資料等補強。】

五、除斥期間(民法第245條):民法第245條條文為「知有撤銷原因」,以債權人實際知悉為準,條文未使用「可得知」。原告公司有權代表人實際知悉贈與及移轉登記之時點,先位主張為112年10月12日調閱登記謄本時;被告甲既為贈與人,其知悉為行為人自知,因與公司有利益衝突,其知悉不應歸責於公司(此為依法律知識及類推民法第106條法理之主張,尚無直接判例)。【起訴日卷內未載,須確認起訴在知悉後一年內且在行為後十年內(行為日104年7月15日,至114年7月屆滿);若起訴日晚於行為後十年,撤銷權即告消滅。另112年10月12日調閱謄本之人、身分及授權,卷內未見,待調閱申請書及規費收據等佐證。】

六、程序事項:原告公司以丙為法定代理人起訴,丙之身分及代表權來源卷內未載,尚待補正。原告將調閱商工登記、清算人就任或法院選任資料、股東同意書,並請法院依職權調查;法院應依職權調查實際代表權,不得僅憑登記認定欠缺(參最高法院115年度台抗字第105號裁定)。如有欠缺而可補正,依民事訴訟法第249條第1項命補正。又商工登記查核本次未進行(雙方均未提供統一編號),不能據此推定當事人能力或法定代理無欠缺。
