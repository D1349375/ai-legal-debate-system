### V35 的邊界

- **法官改用別的說法**:法官輸出裡四個硬擋詞的承認用法是 0,但出現「你方自己也寫」「原告自己也表示」「被告 Stage 3 自己寫明」「被告 Stage 3 自己指出」4 處。逐句看,內容都對得到原文,沒有把假設或資料缺口寫成承認事實;但其中「自己寫明「起訴日卷內未載,不寫成已逾期」」括號內不是逐字(被告 Stage 2 原句是「惟起訴日卷內未載,本方不寫成已逾期」,Stage 3 是「起訴日未載,故仍屬「待確認」,不寫成已逾期」),「自己指出」引用的是段落外的自我評估。手冊說換詞交給人工抽查,這次照記。
- **「承認」**:評估寫原告「民法第184條第1項降為純備位,並承認受民法第197條時效風險壓制」,沒有引述,對應的是原告 Stage 2 的自我評估「須承認有明顯時效風險」。法官範本第 13 行禁止把自我評估寫成「承認」,但「承認」不在硬擋詞表(T3 決定不納入),所以 `check-judge` 放行。其他 3 處「承認」是法律用語(「確定判決或承認」)或「非承認」。
- **雙方論證**:原告 Stage 3 寫「對造自己亦承認「起訴日卷內未載」」,引述的原句在被告 Stage 2 公開論證,但這是被告標的資料缺口。雙方論證只警告,和 W0 的 F4 同類,維持只警告。
