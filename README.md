# AI 法律攻防與專業訴狀系統（LegalDebate AI）
## 專案設計、技術架構與商業評估總覽

> **系統定位**：結合「多 Agent 模擬攻防辯論」與「專業法言法語 Skill 蒸餾」之高階法律輔助與訴狀生成系統。  
> **核心亮點**：在訴狀生成前，先讓「原告律師 AI」與「被告律師 AI」針對案件糾紛進行結構化攻防演練，抓出合規漏洞與對手潛在死穴，最終產出具備專業律師水準之起訴狀、答辯狀與存證信函初稿。

## 1. 核心技術架構與三引擎融合

本系統由三大核心模組構成，解決傳統 LegalTech 工具「容易產生 AI 幻覺（編造法條）」與「文字欠缺專業度」之兩大痛點：

```
                    [ 用戶輸入：糾紛經過 / 合約 PDF / 證據清單 ]
                                         ↓
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 知識與零容錯查證引擎（基於 Startup Guide 體系）                        │
│    • 台灣現行法規庫：民法、公司法、勞基法、消保法、刑法條文檢索         │
│    • 實務判例庫：司法院最高法院真實判例/裁判字號檢索                    │
│    • 機械化防幻覺稽核：100% 驗證法條有效性與判決字號真實性               │
└────────────────────────────────────────────────────────────────────────┘
                                         ↓
┌────────────────────────────────────────────────────────────────────────┐
│ 2. 多 Agent 模擬攻防引擎（基於 DebateSystem 體系）                       │
│    • 原告律師 Agent：尋找最有利主張、求償依據、請求權基礎               │
│    • 被告律師 Agent：尋找免責條款、程序瑕疵、對方舉證漏洞               │
│    • R1 獨立盲判 → R2 結構化反駁：產出案件爭點與「最脆弱死穴清單」        │
└────────────────────────────────────────────────────────────────────────┘
                                         ↓
┌────────────────────────────────────────────────────────────────────────┐
│ 3. 專業訴狀蒸餾生成引擎（基於 女媧 Skill 蒸餾體系）                      │
│    • 載入 `taiwan-legal-pleading` Skill（涵蓋法院默認習慣與法言法語）   │
│    • 訴之聲明精準化（利息、違約金、管轄法院完整標註）                    │
│    • 事實與理由三段論（法律依據前置 → 事實歸入 → 結論）                  │
└────────────────────────────────────────────────────────────────────────┘
                                         ↓
                    [ 最終輸出：案件攻防評估報告 + 合規起訴狀初稿 ]
```

## 3. 端到端使用者體驗流程 (User Journey)

1. **資訊輸入**：用戶輸入糾紛經過白話描述，並上傳相關合約 PDF 或對話截圖。
2. **法理與判例匹配**：系統自動調取台灣現行法條與相關最高法院判例（Startup Guide 查證模組）。
3. **AI 模擬攻防辯論**：
   - 原告 Agent 提論點 A；被告 Agent 根據免責條款進行 R2 反駁。
   - 系統標註出「本案最大的 2 個舉證弱點」與「建議補充之證據」。
4. **專業訴狀生成**：調用 `taiwan-legal-pleading` Skill，15 秒內生成符合司法院格式之 Word/PDF 起訴狀或存證信函初稿。

## 4. 商業化與最嚴苛風險評估 (Risk Assessment)

### ⚠️ 致命死穴與合規政策
1. **《律師法》第 127 條刑事死穴**：對 B2C 一般民眾收費代寫訴狀面臨 3 年以下有期徒刑之刑事檢舉風險。**本專案 100% 絕不做 B2C 大眾收費訴狀網站**。
2. **B2B 律師事務所定位**：僅作為律師內部之「實習律師起草 Copilot ＋ 開庭前攻防預演系統」，或作為律所技術後台（100% 合法合規）。
3. **文件層級檢索錯配（DRM）**：台灣判決書高度制式化行文容易導致檢索抓錯來源判決書（實測錯誤率可超過 95%），須以摘要增強分塊法（SAC）等工程手段處理，是產品能否被律師信任的底線問題。
4. **全球化與對外募資（選配，非核心目標）**：技術上可對標 Harvey AI / Legora 適配美英法系市場，但蒸餾語料與 RAG 資料庫綁定台灣司法管轄區，移植需重新蒸餾建庫，非直接適配；僅在台灣市場站穩後才需評估，詳見 [`YC投資調研報告.md`](./YC投資調研報告.md)。

> 核心判斷標準：**能否被台灣執業律師實際使用**，而非能否被投資人認可。
